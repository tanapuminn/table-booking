# ความคืบหน้าและรายการงานค้าง

บันทึก ณ 26 ตุลาคม 2026 เพื่อใช้กลับมาทำงานต่อ

## งานที่ต้องทำต่อ

- [ ] **เพิ่มโซนแล้วแสดงในหน้าแอดมินทันที** — หลัง `POST /api/zones` สำเร็จ หน้า Dashboard เรียก `updateZoneConfig` ซึ่งแก้ไขได้เฉพาะโซนที่อยู่ใน state แล้ว จึงอาจไม่เห็นโซนใหม่จนกว่าจะรีเฟรช (`app/psmnlp-dashboard/page.tsx`, `components/booking-provider.tsx`)
- [ ] **แสดงผลการบันทึกของแอดมินตาม API จริง** — เปลี่ยนราคา เปิด/ปิดโซน ตั้งค่าการจองรายที่นั่ง ย้ายโต๊ะ และรีเซ็ตผัง ยังมีจุดที่แจ้งสำเร็จก่อน API ตอบ หรือ provider กลืน error (`app/psmnlp-dashboard/page.tsx`, `components/table-layout-editor.tsx`, `components/booking-provider.tsx`)
- [ ] **ป้องกันชื่อโต๊ะซ้ำหลังลบโต๊ะ** — การตั้งชื่อโต๊ะใหม่ใช้จำนวนโต๊ะในโซน + 1 ซึ่งอาจซ้ำกับชื่อโต๊ะที่เหลืออยู่ (`components/booking-provider.tsx`)
- [ ] **ทบทวนการเก็บขนาดผังโต๊ะ** — ปัจจุบันเก็บใน `localStorage` ต่อเบราว์เซอร์ ต้องตัดสินใจว่าจะให้ขนาดผังเหมือนกันทุกเครื่องของแอดมินหรือไม่ (`components/table-layout-editor.tsx`)
- [ ] **Redesign หน้า Dashboard** — รวบรวมความต้องการด้านหน้าตาและลำดับข้อมูลก่อนลงมือออกแบบ
- [ ] **ระบบรีเซ็ตรหัสผ่าน** — กำหนดวิธียืนยันตัวตน ช่องทางส่งลิงก์/รหัส และอายุการใช้งานก่อนพัฒนา
- [ ] **ปรับรายงาน Excel** — เพิ่มชื่อและชั้นของผู้ที่นั่งในแต่ละที่นั่ง พร้อมกำหนดรูปแบบเมื่อหนึ่งการจองมีหลายที่นั่ง (`table-api/src/controllers/bookingController.js`)

## งานที่พักไว้

- รายงาน Excel เมื่อไม่มีรายการจองยังไม่มีหัวคอลัมน์ ผู้ใช้ขอพักไว้ก่อน อาจทำพร้อมการปรับรายงาน Excel ข้างต้น
- ฟีเจอร์ดาวน์โหลดตั๋วถูกเอาออกแล้ว ไม่ต้องนำกลับมาในรายการงานโดยอัตโนมัติ

## งานที่ทำแล้วในรอบล่าสุด

- ตรวจสิทธิ์หน้า Dashboard ใน middleware ก่อนเปิดหน้า; API ข้อมูลแอดมินยังตรวจสิทธิ์ของตัวเอง
- หน้าตั๋วแสดงตามสถานะการจองจริง และลบโค้ดดาวน์โหลดตั๋วที่ไม่ใช้
- ปุ่มส่งออก Excel แจ้งข้อผิดพลาดเมื่อดาวน์โหลดไม่สำเร็จ
- ป้องกันการลบโต๊ะ/โซนที่มีประวัติการจอง และป้องกันการลบโซนที่ยังมีโต๊ะ
- ตั้งเวลาให้ชำระเงินและเปิด/ปิดรับจองผ่านแอดมินได้
- ผู้ใช้ยืนยันว่านับเวลาถอยหลังและคืนที่นั่งเมื่อหมดเวลาใช้งานได้แล้ว

## ข้อตกลงของระบบที่ยืนยันแล้ว

- หน้า Home ไม่เรียก `GET /api/bookings` เพื่อดึงรายการจองทั้งหมด
- แอดมินทุกบัญชีดูและจัดการรายการจองทั้งหมดใน Dashboard ได้
- ประวัติการจองใน Profile แสดงเฉพาะรายการของบัญชีนั้น ไม่ขึ้นกับ role แอดมิน
- งาน Excel กรณีไม่มีรายการจองยังไม่ทำในตอนนี้

## จุดตรวจล่าสุด

- Backend: `RUN_DB_TESTS=true npm test` ผ่าน 32/32 รายการ
- Frontend: `npx tsc --noEmit` ผ่าน
- Middleware: `node --test test/middleware.test.cjs` ผ่าน
- ยังมีการแก้ไขในทั้งสอง package ที่ไม่ได้ commit; ตรวจ `git status` ก่อนเริ่มงานรอบถัดไป
